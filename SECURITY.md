# Security

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/ArcdrakeStudios/redact-this/security/advisories/new).
Do not open a public issue containing exploit details, credentials or personal data.
Provide a minimal synthetic reproduction, affected revision, impact and browser details.
There is no guaranteed response time. Only the latest version on `main` is maintained;
there are no supported older release branches yet.

For ordinary bugs without sensitive information, use the issue tracker.
The README describes the app's privacy boundaries and limitations.
